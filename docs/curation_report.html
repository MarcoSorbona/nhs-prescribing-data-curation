Executive Summary

This report documents the curation of the English Prescribing Dataset (EPD) with SNOMED Code, a monthly NHS dataset capturing all primary care prescriptions dispensed in England.

Data scale: 7 GB per month, 17M+ rows monthly

Curation approach: CKAN API with R data frame processing (sample: 10,000 rows per month)

Memory usage: < 2 GB

**Sample processed**: 40000 rows across 4 months ( 202311 to 2026-01 )

Data Source & Attribution

Source: NHS Business Services Authority. “English Prescribing Dataset (EPD) with SNOMED Code” NHSBSA Open Data. Accessed 2026-04-23. URL: https://opendata.nhsbsa.net/dataset/english-prescribing-dataset-epd-with-snomed-code

Access Method: CKAN API (https://opendata.nhsbsa.net/api/3/action/datastore_search)

Key Data Quality Discoveries

1. Missing Drug Names in API Data

Challenge: The API endpoint for certain years returned zero bnf_presentation_name values.

**Affected year(s):** 2023

- **20000 rows** affected
- **104,680 items**
- **£930,237 in prescribing costs** cannot be attributed to specific drugs

Challenge: The API endpoint for certain years returned zero bnf_presentation_name values.

Solution: Documented limitation; flagged affected rows with corruption_flag; recommend excluding affected months for drug-level analysis.

2. Inconsistent Date Formats Across Years

Challenge: API returned different date formats for different years (observed in the data).

Solution: Standardised using case_when() before time series analysis.

3. Serious Shortage Protocols (SSPs)

Challenge: No flag for SSP claims; dispensed drug ≠ prescribed drug.

Limitation: Cannot identify SSP-impacted prescriptions from EPD alone.

Mitigation: Documented limitation in quality report and dashboard disclaimer.

4. Negative Quantities (Returns)

Challenge: Returns to pharmacy appear as negative quantities.

Decision: Retain in dataset; documented.

5. Missing Lookup Matches

Challenge: Practice and BNF codes may not match lookup tables.

Action: Left joins with reporting of match rates.

Limitations (Official NHSBSA Caveats)

  1. PGD exclusions: Pharmacy First, contraception, smoking cessation not captured
  2. Dental prescribing: Excluded entirely
  3. Hospital site codes: Excluded (only cost centre codes included)
  4. SSPs: Cannot be identified from EPD alone
  5. Code versioning: BNF/SNOMED codes may change over time

Data Quality Issue: Missing Drug Names

Discovery

The API endpoint for certain years returned zero drug names.

Impact Assessment

  • Drug-level analysis not possible for affected months
  • Regional and monthly totals remain valid

Proposed Resolution (Production Context)

Step Action
1 Download full CSV files from NHSBSA portal
2 Use CSV pipeline instead of API
3 Join with appropriate BNF lookup

Decision for This Portfolio

Documented as a data quality discovery rather than resolved, to demonstrate issue identification skills.

Usage Notes

To reproduce this curation:

  1. Clone this repository
  2. Ensure lookup tables are in data/lookup/
  3. Run the curation pipeline: Rscript R/01_curate_epd_api.R
  4. Render this report: quarto render curation_report.qmd
  5. Render the dashboard: rmarkdown::render("epd_dashboard.Rmd")
